# Safety Inspection Logbook

This is a simple HTML-based logbook designed for tracking daily or weekly safety inspections in the field. No logins, no database — just open the file, print it, or add rows directly.

## 🔍 Features

- Clean, printable safety inspection table
- Columns for inspector, equipment, location, and issues
- Lightweight and fast — runs completely in browser
- Great for trucking, oilfield, jobsite, or warehouse safety use

## 🛠 How to Use

1. Open the file in your browser: `safety_inspection_logbook.html`
2. Print it and fill by hand _or_ right-click > Open With > Code Editor and edit directly.
3. Save a new copy for each inspection log if needed.

## 👷 Use Cases

- Pre-shift safety checks
- Weekly equipment audits
- OSHA & DOT compliance logs
